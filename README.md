# 📊 전략 검증기

유튜브·블로그에서 본 매매 규칙이 **"그냥 사서 들고 있기"보다 정말 나았는지** 과거 데이터로 정직하게 비교하는 웹앱입니다.
투자 조언이 아니며, 과거 결과가 미래를 보장하지 않습니다.

## 할 수 있는 것
- 종목 찾기: 영어 이름(`apple`, `bitcoin`), 코인 한글 이름(`비트코인`, `수이` — 업비트 원화 마켓 목록), 야후 코드(`MSFT`, `BTC-USD`, `BTC-KRW`)
- **한 종목**: 규칙 하나(또는 조합)를 그 종목 "그냥 들고 있기"와 비교 (실험 001 방식)
- **여러 종목(후보군)**: 후보 중 조건을 충족한 종목을 RSI 낮은 순으로 N칸에 나눠 담고, 빈 칸은 비교 기준 지수에 넣어 둔다. 매일 또는 주 1회 사고판다. 판정은 비교 기준 지수와 비교 (실험 003·004 방식, 최대 30종목)
- 규칙: 교과서 지표 7개(200일선, 골든크로스, RSI, MACD, 볼린저, OBV, 변동성 돌파) 중 하나, 또는 여러 개를 다수결·전부 충족으로 조합 (변동성 돌파는 단독만)
- 설정: 시작일, 검증 시작일(학습/검증 구간 경계), 종료일, 1회 거래 비용
- 결과: 전략 · 그냥 들고 있기(여러 종목은 후보 균등 보유) · 비교 기준(주식은 다우 지수 ETF `DIA`, 코인은 같은 통화의 비트코인 `BTC-USD`/`BTC-KRW`)의 총수익률·CAGR·MDD·매수 횟수, 자산 곡선, 통과 판정

## 계산 방식
- 그날 종가로 신호 계산 → 다음 날 시가에 체결, 사고팔 때마다 비용 차감, 사기만 함(공매도 없음)
- 변동성 돌파만 당일 매수 → 다음 날 시가 매도
- 통과 기준: 구간마다 CAGR이 들고 있기보다 높거나, 차이 연 2%p 이내이면서 MDD가 절반 이하. 학습·검증 **둘 다** 통과해야 "후보"
- 세금·환율 제외. 데이터는 야후 무료 일봉(분할·배당 반영)이고 12시간 캐시

## 안 하는 것 (첫 버전)
